# 아메리카 대륙 스테이지 재설계 — "아메리카 탐험 항로"

> 작성일 2026-08-31 · 대상: 초등 사회(세계 여러 나라) · 태블릿 가로형 기준
> 사용자 브리프(PHASE 1~9)가 구조를 확정했으므로 콘셉트 3안 비교는 생략하고,
> game-idea 원칙(게임성·난타 금지·태블릿 타당성·다문화 원칙) 검사를 통과시키는 상세 설계로 바로 간다.

**한 줄 콘셉트**: 한국에서 출발한 탐험 비행기가 아메리카 대륙에 착륙해, 지도를 직접 만지며
네 나라의 자연·생활·문화를 탐험하고, 그 나라에서 살아가는 친구 4명을 만나
"다른 점 속의 공통점"을 발견해 지구회의(Stage 6)로 가져가는 여행형 학습 스테이지.

**CORE LOOP**:
`지도에서 위치 찾기 → 렌즈로 환경 관찰 → 나라 속으로 들어가 탐험 → 그곳에 사는 친구 만나기 → 가방 속 문화 꺼내 보기 → 발견을 탐험 노트에 저장 → 다음 나라`

---

## 1) 전체 스토리 흐름

```
비행기가 태평양을 건너 아메리카에 접근 (착륙 연출)
→ "여기가 어디지?" 대륙 전체를 손으로 움직이며 파악        [PHASE 1]
→ 친구 4명의 엽서가 도착 — "우리 나라를 찾아와!" 위치 찾기  [PHASE 2]
→ 탐험 렌즈(위치/자연/생활)로 대륙이 다르게 보임            [PHASE 3]
→ 나라마다 다른 방식의 마이크로 탐험 (4회 반복, 순서 자유)   [PHASE 4]
→ 탐험 끝 지점에서 그 나라 친구가 기다림 — 문화 가방 열기    [PHASE 5]
→ 네 친구의 하루 비교 — 같은 시간, 다른 장면, 닮은 마음      [PHASE 6]
→ 탐험 노트 정리 — 발견을 분류·연결                        [PHASE 7]
→ 네 친구와 함께 연결 키워드 완성                          [PHASE 8]
→ 친구들이 지구 신호를 건넴 → 지구회의(Stage 6)로 전달      [PHASE 9]
```

이야기 장치: **탐험 노트**. 화면 하단에 항상 떠 있는 작은 수첩으로,
학생이 발견할 때마다 스티커가 붙는다(숫자 카운터 없음 — 채워지는 그림으로만 표현).
이 노트가 PHASE 7의 재료가 되고, 마지막에 지구 신호로 바뀐다.

## 2) 화면별 진행 순서 (+ 3·4·5번 항목 통합: 학습 목표 / 플레이어 행동 / 상호작용)

9개 PHASE를 **6개 화면**으로 묶는다. 화면이 9개면 8~12분 예산을 넘고 리듬이 늘어진다.

### 화면 A — 아메리카 착륙 (PHASE 1+2)
- **학습 목표**: 아메리카 대륙의 위치(태평양 건너), 북/남아메리카 구분, 네 나라의 상대 위치
- **플레이어 행동**: ① 착륙 연출을 본 뒤 대륙 지도를 드래그·핀치로 둘러본다
  ② 친구 4명의 엽서(사진+한 줄)가 화면 옆에 도착 → 엽서를 **지도 위 맞는 자리로 드래그**한다
- **상호작용**: 지도 팬/핀치줌(포인터 이벤트), 엽서 드래그 배치.
  엽서에는 위치 힌트가 있다("나는 대륙의 북쪽 끝, 바다 세 개에 닿은 나라에 살아").
  틀린 자리에 놓으면 엽서가 흔들리며 힌트 한 줄이 추가된다 — 정답 공개가 아니라 단서 추가.
- **난타 검사**: 자리 4곳 × 엽서 4장을 무작위로 놓으면 16회 시도로 뚫린다 → 오답 시 해당 엽서가
  1.2초 잠기고 힌트가 갱신되어, 힌트를 읽는 쪽이 빠르게 된다.

### 화면 B — 탐험 렌즈 (PHASE 3)
- **학습 목표**: 같은 대륙이 위치·자연·생활 렌즈에 따라 다르게 읽힘. 로키·안데스 산맥,
  아마존강, 대평원, 해안선 / 도시와 마을의 분포
- **플레이어 행동**: 하단의 렌즈 3개(위치/자연/생활)를 전환하며 지도 자체가 변하는 것을 관찰,
  각 렌즈에서 빛나는 지점 2~3곳을 눌러 짧은 발견 문장을 수집
- **상호작용**: 렌즈 전환 = 지도 레이어 크로스페이드(CSS opacity, 이미지 2~3장 겹침).
  팝업 대신 지도 위 라벨이 직접 나타난다. 발견 지점을 누르면 탐험 노트에 스티커가 날아가 붙는다.
- **구현 노트**: 레이어는 같은 구도의 지도 일러스트 3장(위치=국경+바다 강조 / 자연=지형 강조 /
  생활=도시 불빛 강조). 이미지 3장으로 해결 — 에셋 예산 안에서 가능.

### 화면 C — 나라 마이크로 탐험 + 친구 만나기 (PHASE 4+5, 나라당 1회 × 4)
지도에서 나라를 누르면 그 나라 장면으로 들어간다. **나라마다 조작이 다르다**(6번 항목 참조).
탐험이 끝나는 지점에 친구가 서 있고, 문화 가방을 연다.

- **학습 목표**: 나라 안에도 여러 환경·생활이 있음(한 나라 = 한 이미지 금지),
  자연환경과 생활 모습의 연결
- **플레이어 행동**: 나라별 고유 조작으로 장면 2~3곳 탐험 → 친구 인사 → 가방에서 아이템 3~4개를
  직접 꺼내 보고/듣고 → 그중 "지구회의에 가져가고 싶은 것" 1개를 노트로 드래그
- **상호작용**: 나라별 상이(§6). 가방 아이템 = 탭하면 사진+소리+친구의 한 줄
  ("우리 지역에서는~", "우리 가족은~" 화법). 아이템 중 1개는 반드시 환경과 연결된 것.
- **난타 검사**: 가방 아이템은 모두 꺼내야 다음으로 가지만, "가져갈 1개 고르기"는
  아무거나 골라도 통과된다 — 대신 고른 이유가 PHASE 8 키워드 완성에서 다시 쓰이므로
  선택이 의미를 가진다(선택≠정답, 선택=재료).

### 화면 D — 같은 대륙, 서로 다른 하루 (PHASE 6)
- **학습 목표**: 차이(환경·문화)와 공통점(학교, 가족, 놀이, 먹는 즐거움)을 동시에 발견
- **플레이어 행동**: 아침/학교/오후/저녁 4개 시간대를 좌우 스와이프. 각 시간대에 네 친구의
  장면 카드가 나란히 보인다. 학생은 시간대마다 **"닮은 점 하나"를 두 카드를 이어서** 표시한다
- **상호작용**: 가로 스와이프(스냅 스크롤), 카드 2장 탭-탭 연결(선이 그어짐).
  연결하면 친구들의 짧은 반응 대사("너도 아침에 그거 해? 나도!").
  기존 `plan`(하루 만들기) 화면의 시간대 데이터 구조를 재활용한다.
- **난타 검사**: 아무 카드나 이으면 "정말? 어떤 점이 닮았는지 다시 봐 줘" + 카드 확대 —
  닮은 점이 성립하는 조합(콘텐츠에 정의)만 선이 유지된다.

### 화면 E — 탐험 노트 펼치기 (PHASE 7+8)
- **학습 목표**: 수집한 발견을 자연환경/생활·문화/여러 나라 공통으로 분류하고,
  "서로 다른 자연환경 · 다양한 문화 · 비슷한 생활 · 함께 사는 지구" 연결 구조를 스스로 완성
- **플레이어 행동**: 노트에 모인 스티커(렌즈 발견+가방 선택+하루 연결)를 3개 영역 보드로 드래그 분류
  → 분류가 끝나면 네 친구가 다시 등장, 영역 사이를 잇는 키워드 빈칸 2개를 후보에서 골라 완성
- **상호작용**: 카드 드래그 분류(기존 `classify` 화면의 dnd 로직 재활용), 영역 간 연결선,
  키워드 슬롯 채우기. 애매한 카드는 두 영역 사이에 걸쳐 놓을 수 있다(정답 하나 강요 금지).
- **난타 검사**: 잘못 분류하면 카드가 되돌아오는 대신 친구가 질문한다
  ("이건 자연 때문일까, 사람들이 만든 걸까?") — 재분류 기회.

### 화면 F — 지구 신호 전달 (PHASE 9)
- **학습 목표**: 아메리카에서 발견한 것이 다른 대륙·지구 전체와 연결됨을 예고
- **플레이어 행동**: 완성된 노트가 접히며 **지구 신호 3개**(물/숲/생활)로 변환되는 연출을 보고,
  신호를 세계지도 위 자기 항로에 직접 놓는다 → 도장 + Stage 6 예고 대사
- **상호작용**: 신호 토큰 드래그 1회 + 완료 연출. 짧게 끝낸다(마무리 화면은 1분 이내).

## 6) 나라별 탐험 로직 (캐나다/멕시코/브라질/페루)

| 나라 | 조작 방식 | 탐험 흐름 | 조작이 학습과 연결되는 이유 |
|---|---|---|---|
| **캐나다 (노아)** | **가로 항해 드래그** — 세 바다(태평양·북극해·대서양)에 닿은 긴 국토를 배/경비행기로 좌→우 이동 | 서부 해안 → 내륙 평원·도시 → 동부 해안, 장면마다 정지해 관찰 | "넓다·바다 셋에 닿는다"를 손으로 끌어 본 거리감으로 체감 |
| **멕시코 (카밀라)** | **지형 경로 따라가기** — 해안→고원→산지로 이어진 길을 손가락으로 그리며 이동 | 경로 위 갈림길에서 어느 지형으로 갈지 선택, 지형마다 생활 장면이 다름 | 지형 차이→생활 차이를 경로 선택의 결과로 관찰 |
| **브라질 (아나)** | **강 따라 내려가기** — 아마존강 물줄기를 따라 카누가 이동, 학생이 물길을 탭해 방향 결정 | 상류 숲 → 강변 마을 → 하구 → 남동부 대도시·해안으로 점프 | 큰 강이 숲·마을·도시를 잇는다는 공간 감각 |
| **페루 (마테오)** | **고도 슬라이더** — 세로 슬라이더를 올리면 해안(0m)→안데스(4,000m)→내려가면 아마존 | 고도에 따라 배경·옷·생활 장면이 실시간으로 변함 | "한 나라 안에서 고도가 환경을 바꾼다"를 조작 자체로 학습 |

네 조작이 전부 다르므로 "모든 상호작용이 한 가지 구조" RED FLAG 회피.
각 나라 장면 2~3곳 = 파노라마 이미지 1장을 배경 포지션 이동으로 처리(아프리카 지역 탐험과 같은 기법, 코드 재사용).

## 7) 나라별 지리 학습 요소

- 캐나다: 북아메리카 북부, 세 대양 접함, 넓은 국토, 서부 산지/중부 평원/동부 도시권의 차이
- 멕시코: 북아메리카 남부, 태평양·멕시코만 사이, 고원과 산맥, 해안-고원 기후 차이
- 브라질: 남아메리카 최대, 아마존강과 열대우림, 남동부 해안 대도시, 적도 통과
- 페루: 남아메리카 서부, 해안사막-안데스-아마존의 3단 환경, 고도와 기후
- 공통: 북/남아메리카 구분, 태평양·대서양과의 관계, 적도 위치 [검증 필요: 교과서 표기 기준 지명·구분]

## 8) 나라별 문화 학습 요소 (문화 가방 내용, 각 3~4개)

원칙: 상징 고정 금지, "우리 지역/우리 가족" 화법, 아이템 중 1개는 환경 연결.

- **노아**: 지역마다 다른 겨울/여름 놀이, 여러 언어가 쓰이는 학교[검증 필요], 바다·숲과 이어진 생활, (환경) 넓은 숲 이야기
- **카밀라**: 가족 모임과 음식(한 가지 음식으로 고정하지 않고 "고원 지역 우리 집" 맥락), 광장 문화, 음악, (환경) 물이 귀한 지역의 지혜
- **아나**: 강변 마을과 대도시의 서로 다른 하루, 음악·춤(지역 다양성 명시), 학교생활, (환경) 아마존 숲의 변화
- **마테오**: 고도별로 다른 옷과 시장, 안데스 음악, 감자·옥수수의 고향 이야기[검증 필요], (환경) 빙하와 물 이야기
- 모든 아이템은 출처 링크 유지(기존 sources 구조 재사용).

## 9) 기존 친구 캐릭터 활용 방식

- 4명 캐릭터·이름·국적 유지. 다만 등장 시점을 바꾼다: 처음부터 4명이 나오지 않고
  **엽서(A) → 자기 나라 탐험 끝(C)에서 실물 등장 → 하루 비교(D) → 피날레(E·F)** 순서로 재등장.
- 캐릭터 = 진행 UI: 지도 화면에서 이미 만난 친구는 자기 나라 위에 작게 서 있다(방문 표시를 숫자 대신 캐릭터로).
- 기존 대화(dialogue)·하루(plan) 콘텐츠는 D 화면 장면 카드와 C 화면 친구 대사로 재배치한다.

## 10) 유지 / 수정 / 삭제

| 구분 | 대상 |
|---|---|
| **유지** | 4인 캐릭터와 성격, students 콘텐츠(needs/prefs/culture/dialogue), 분류 dnd 로직, 시간대(plan) 데이터, 학습 카드·learnFrame 연결, 저장 체크포인트 구조, 출처 표기 |
| **수정** | `profiles` → 화면 A+C로 분해(엽서+현지 만남) · `classify` → 화면 E 탐험 노트 분류로 재목적화 · `talk` 대화 → C 화면 가방 열기 전후 대사로 축약 · `plan/alt`(하루 만들기·비교) → 화면 D "하루 비교"로 전환(내 시간표 만들기 → 친구들 하루 비교) |
| **삭제** | "어울림 학급" 교실 프레임(학급에 온 전학생 설정) — 여행 프레임과 충돌. `alt` 플랜A/B 비교 로직(비교 대상이 계획이 아니라 친구들의 하루가 됨) |

## 11) Stage 6에 넘길 지구 연결 신호

프로젝트 전체에서 "단서" 표현은 쓰지 않기로 했으므로 **"지구 신호"**로 명명(기존 환경 신호·지구회의 구조와 일치).

- `signal.water.americas` — 물: 아마존강/안데스 빙하에서 발견한 물 이야기
- `signal.forest.americas` — 숲: 아마존·캐나다 숲의 변화
- `signal.life.americas` — 생활: 환경이 달라도 닮아 있는 아이들의 하루
- 저장: `S.earthSignals: string[]`를 미션 아티팩트(writeMissionArtifact)와 세이브에 기록,
  Stage 6(missionDialogue/earthCouncil)에서 대륙별 신호로 읽어 회의 재료로 사용.
  [가정] Stage 6 쪽 읽기 로직은 별도 작업으로 추가.

- prefers-reduced-motion 대응 필수

## 15) 태블릿 활용 타당성 (§9 검사 — 2개 이상 필요, 실제 8개)

핀치 줌 · 지도 드래그 · 엽서/스티커/신호 드래그 · 경로 직접 그리기 · 고도 슬라이더 ·
레이어 전환 즉시 반응 · 소리(음악·인사말) 듣기 · 상태 저장(노트가 세션 간 유지).
종이로는 "고도를 올리면 풍경이 변한다"와 "렌즈에 따라 같은 지도가 다르게 보인다"를 재현할 수 없다.

## 16) 학생 흥미 요소

- 나라마다 조작이 달라서 "다음 나라는 어떻게 탐험하지?" 기대감
- 문화 가방 = 뽑기형 호기심(무엇이 들었을까) + 소리·사진 중심
- 탐험 노트가 눈에 띄게 채워지는 수집 재미(숫자 없이 그림으로)
- 친구들의 반응 대사("너도 그래? 나도!")가 연결 행동의 보상
- 마지막에 내 발견이 지구 신호가 되어 다음 스테이지로 이어지는 서사

## 17) 다문화 교육상 주의점 (브리프 §6 반영)

- 모든 친구 대사는 "우리 지역에서는/우리 가족은/다른 지역엔 또 다른 모습도 있어" 화법으로 작성
- 나라=상징 1개 금지: 가방 아이템·탐험 장면 모두 최소 2개 이상의 지역/맥락 제시
- 빈곤·낙후·이국적 소비 프레임 금지: 환경 이야기도 "걱정과 돌봄" 관점으로, 특정국 비난 없이
- 문화 아이템은 반드시 생활 맥락(누가, 언제, 왜)과 함께 제시
- 사실 정보(지명·언어·음식 기원 등)는 [검증 필요] 표시 후 출처 확정 전 확언 금지
- learning-check 스킬로 콘텐츠 작성 후 검수
