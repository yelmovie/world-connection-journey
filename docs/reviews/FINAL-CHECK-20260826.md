## 220/220을 위한 단계별 계획

### 0단계 — 즉시 코드 개선

**완료.** 존재 이유·선택 효용·미션 보상·학습 산출물·전이 답·팝업·타이포·설정 정보를 코드와 화면에 반영했다.

### 1단계 — 교육 타당도와 재미 실측

1. 초등학생 8~12명에게 설명 없이 시작하게 하고 첫 행동까지 걸린 시간, 중단 지점, 자발적 재도전을 기록한다.
2. 각 미션 직후 “무엇을 근거로 생각을 바꿨나?”, 완료 뒤 “새 상황에서 무엇을 할까?”를 받아 설명 가능한 근거 수와 전이 답의 질을 비교한다.
3. 사회과·다문화교육 담당자 1명 이상이 문화 범위·표현·출처를 검수하고 `needsReview` 메타데이터에 검수자·날짜·수정 근거를 남긴다.

통과 기준: 학생 80% 이상이 도움 없이 목적을 설명하고, 6개 중 5개 이상 미션에서 선택 이유를 말하며, 완료 학생 80% 이상이 구체적인 생활 전이 행동을 쓴다.

### 2단계 — 관련성이 약한 스테이지 보강

1. 유럽: 관광 동선 중심에서 주민 2인의 보존·접근성·일상 갈등을 듣고 경로를 재수정하는 구조로 강화한다.
2. 아프리카: 악기마다 실제 지역 지도·음악가 목소리·사용 맥락을 붙이고 대륙 전체 일반화를 막는다.
3. 아시아: 하나의 네팔 사례 뒤 두 번째 친구 자료를 비교해 ‘개인 사례≠대륙 전체’ 원리를 조작으로 확인한다.
4. 새 이미지를 만들기 전에 `docs/ASSET_UNUSED_CANDIDATES.md`의 친구·의상·악기·여행 소품을 학습 맥락에 맞게 우선 검토한다.

### 3단계 — 재플레이와 최종 협의 심화

1. 아시아·유럽·아프리카·아메리카에 상황 덱 3종을 추가한다.
2. 속도·정답률 대신 ‘근거 수집·목소리 포함·판단 수정’으로 우열 없는 관점 배지를 준다.
3. 최종 회의에서 주민의 현실적 이의 제기→조항 수정→새 상황 적용을 한 번 더 수행한다.

### 4단계 — 코드·교실 환경

1. 대형 미션 파일을 state/data/view/evaluation 단위로 나누고 공통 stage shell을 만든다.
2. 미사용 에셋을 실제 참조와 육안 중복 확인 후 보관 폴더로 이동하고, BGM 최초 전송량을 줄인다.
3. 768×1024 실기기 회전, 가상 키보드, 저사양 FPS·메모리, 학교 와이파이 냉시작을 측정한다.
4. 온라인 1회 뒤 와이파이를 끄고 첫 화면→여섯 도장→전이 회고→수료증까지 완주한다.
