## 이번에 적용한 핵심 개선

1. **초등학생이 이해하는 흐름으로 변경**
   - 아메리카·유럽 시작 팝업의 의미 없는 답 선택을 제거했다.
   - 나라를 맞히는 인사 퀴즈를 없애고, 관계·상황·개인에 따라 달라지는 인사를 관찰하게 했다. `src/pages/missionDialogue.ts:434`
   - 아시아 질문 만들기의 숨은 정답 조합을 제거하고, 열린 질문이면 모두 인정한다. `src/pages/missionAsia.ts:935`
   - 수치 경쟁 표현을 ‘공감 점수’에서 ‘찾은 대화 단서’로 바꿨다. `src/pages/missionDialogue.ts:659`

2. **문화 설명과 고정관념 방지**
   - 아메리카 4명 모두 문화 배경 → 개인 이야기 순으로 말한다.
   - 노아의 이름 문장을 ‘원래 발음대로’ 같은 모순 표현 대신 ‘사람마다 원하는 발음이 다르니 직접 물어본다’로 고쳤다.
   - 탐험가를 특정 나라의 외모로 표시하지 않고 ‘관찰·질문·지도·함께 생각’ 역할로 바꿨다. `src/ui/avatarRoster.ts:8`
   - 네팔 생활 사례와 오세아니아 환경 수치는 게임 속 한 사례·모형임을 명시했다.

3. **선택의 의미와 화면 연결**
   - 여권에서 고른 정확한 탐험가·비행기 이미지를 지도·전환·미션·완료 화면까지 연결했다. `src/ui/airplaneFleet.ts:31`, `src/pages/map.ts:279`
   - 여권 책 안의 긴 역할 문장을 줄여 이름 칸 잘림을 없앴다. `src/pages/passport.ts:251`
   - 지도 마커를 실제 미션 내용에 맞는 친구·천문시계·젬베·섬·대화 문으로 교체하고 패널 겹침을 피했다. `src/pages/map.ts:45`

4. **반응형·접근성·팝업**
   - 저높이 대화·유럽 자료·아시아 보드·아프리카 리듬판은 잘라 숨기지 않고 한 페이지 스크롤로 접근하게 했다.
   - 설정 펼침 항목, 범위 입력, 악기 썸네일의 터치 높이를 44~52px 이상으로 확보했다. `src/styles/components.css:216`, `src/pages/missionAfrica.ts:304`
   - 타이핑 애니메이션의 움직임 줄이기 분기와 모달 종료 타이머 정리를 고쳤다.

5. **실물 자료·저작권·오프라인**
   - 프라하 실제 사진 6장, 아프리카 실제 악기 사진 5장, 오세아니아 주민 에셋 4장을 manifest와 서비스워커에 연결했다.
   - 외부 사진과 자체 AI 제작물을 저작권 문구에서 분리했다. `src/ui/chrome.ts:71`
   - 앱 버전·서비스워커 버전을 0.1.4로 맞추고 빌드 산출물 전체 프리캐시 목록을 생성한다.

## 배포 전 처리할 조건

1. 초등학생 8~12명으로 1회 수업 관찰: 설명 없이 시작 가능한지, 재도전 의사가 있는지, 각 미션에서 배운 말을 자기 말로 설명하는지 기록한다.
2. 사회과 교사 또는 다문화교육 담당자 1인이 `needsReview:true` 콘텐츠를 검토하고 검수자·검수일·근거 출처를 남긴다.
3. 학교 태블릿에서 와이파이를 끊은 뒤 첫 화면→6개 도장→수료증까지 완주한다.
4. 14.29MB 오디오를 필요한 시점별로 더 작게 압축하거나, 학교망 최초 재생 대기 시간을 실측한다.

## 개선 우선순위 — 최저 3개

1. 실제 아동 재미·이해도 관찰(1·3번)

3. 미참조 에셋 후보와 오디오 용량 정리(18번)
