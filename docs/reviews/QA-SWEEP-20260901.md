# 출시 전 화면 전수 점검 (Playwright 자동 스윕) — 2026-09-01

> 실행: `node scripts/qa-sweep.cjs`  (기본 http://localhost:5273 · 프로덕션 확인은 인자로 preview 주소)
> 범위: 3해상도 × 10화면(타이틀·여권·지도·5대륙·스테이지6·완주) + 각 화면 진입 팝업 자동 해제 후 본 화면
> 검사 항목: 글자 잘림 / 빈 버튼 / 버튼 가려짐(실제 클릭 지점 판정) / 작은 터치 영역 / 세로 스크롤 / 빈 여백 패널 / 중복 문구 / 그림 눌림 / 콘솔 오류

## 스윕으로 찾아 고친 것

| 문제 | 원인 | 조치 |
|---|---|---|
| 빈 여백 패널 6건 (유럽 가방·아시아/오세아니아 사이드) | 패널이 남는 세로를 모두 차지 / 구역 선택 전 내용이 거의 없음 | 가방 패널을 내용 높이로(`align-self:start`), 아시아·오세아니아는 **권역 목록 칩**을 미리 노출해 사이드를 채움(지도 핀을 못 찾는 학생의 대체 경로도 됨) |
| 작은 터치 영역 11건 | 아메리카 랜딩 카드 `min-height:0`으로 34px까지 눌림 / 유럽 핀 축소 부작용 | 카드 최소 44px 보장, 유럽 핀은 40px로 절충 |
| 캐릭터 겹침 12건 | 모바일 가로에서 가이드 말풍선이 화면을 가로질러 버튼을 덮음 | 세로 460px 이하에서 가이드 숨김(안내는 하단 상태 줄에 유지), 지도 화면 가이드는 노드보다 아래 레이어로 |
| 본문이 149px밖에 안 됨 | 짧은 화면에서도 상·하단 바가 84/88px 유지 | `max-height:460px`에서 44/48px로 축소(토큰) |
| 지도 핀 밀집·가려짐 | 좁은 세로에서 좌표 기반 핀이 겹침 | 세계지도는 목록 모드를 세로 460px 이하에도 적용, 권역/유럽 핀 축소·안내 문구 숨김 |

## 남은 항목 — 모바일 가로(844×390) 한정

이 해상도는 세로 390px로, 상·하단 바를 최소화해도 본문이 약 300px밖에 남지 않는다.
지도 좌표 UI와 물리적으로 충돌하는 구간이라 아래는 **진행 불가(블로커)가 아니라 제약**으로 남긴다.

| 항목 | 실사용 영향 | 대체 경로 |
|---|---|---|
| 아메리카 지도 확대·축소 버튼이 상단바에 가림 | 낮음 | 두 손가락 핀치 줌으로 동일 조작 가능 |
| 유럽 이탈리아·스페인 핀이 서로 겹침 | 낮음 | 나머지 5개국으로 완료 조건(5개국) 충족 가능 |
| 오세아니아 구역 핀 2개가 위·아래 바에 물림 | 낮음 | 사이드의 **권역 목록 칩**으로 동일 선택 가능(이번에 추가) |
| 세계지도·스테이지6·완주 세로 스크롤 | 낮음 | 목록/카드가 세로로 이어지는 정상 스크롤 |

교실 기준 기기(전자칠판·태블릿 가로 1366×768 이상)에서는 위 항목이 모두 발생하지 않는다.

## 재실행 방법

```bash
node scripts/qa-sweep.cjs                      # dev 서버(5273)
node scripts/qa-sweep.cjs http://localhost:4273 # 프로덕션 preview
```

`scripts/qa-probe.cjs`는 특정 화면의 요소 크기·구조를 자세히 찍어 보는 보조 진단이다.
