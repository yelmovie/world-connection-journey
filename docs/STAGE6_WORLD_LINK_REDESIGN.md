# Stage 6 전면 개편 — 「WORLD LINK : 연결된 지구」

> 작성일 2026-08-31 · 라우트 `#/mission/respect-dialogue` · 태블릿 가로형·전자칠판 기준
> 사용자 브리프(PHASE 1~7)가 구조를 확정. game-idea 원칙(게임성·난타 금지·행동=학습·태블릿 타당성) 검사 적용.

**한 줄 콘셉트**: 다섯 대륙 탐험을 마친 순간 세계지도에 이상 신호가 동시에 켜지고,
학생은 자신이 모아 온 발견·문화·신호를 무기로 "한 나라 구하기"의 실패를 겪은 뒤,
제한된 협력 토큰으로 LOCAL+GLOBAL 작전을 설계해 미래를 바꾸는 최종 작전 스테이지.

**CORE LOOP**:
`신호 관찰(전/후 비교) → 원인-영향 연결 → 입장 체험 → 작전 설계(자원 배분) → 미래 시뮬 관찰 → 남은 연결 확인 → 계획 수정 → 세계 재연결`

**게임의 핵심 반전**: PHASE 4에서 학생이 *스스로* 한 나라 집중 지원을 선택하고 실행한 뒤,
지도를 다시 열면 연결선이 되살아나는 것을 눈으로 본다. "한 나라의 노력만으로는 부족합니다"는
이 실패 **후에만** 등장한다. 설명이 아니라 경험이 결론을 만든다.

## 1) 전체 스토리

```
[프롤로그] 다섯 대륙 친구들의 긴급 영상통화 — "우리 동네에도 신호가 켜졌어!"
[S1 신호 지도] 세계지도 곳곳에 경고 신호. 나라를 터치해 과거↔현재 슬라이더로 변화 관찰   (PHASE 1)
[S2 연결 퍼즐] 내가 모은 발견 카드로 원인→변화→생활→다른 지역 인과 네트워크 완성        (PHASE 2)
              → 완성될 때마다 세계지도에 실제 연결선이 그어진다
[S3 입장 체험] 농촌·해안·도시, 세 지역 사람의 20~30초 배분 시뮬 — 완벽한 답이 없다      (PHASE 3)
[S4 1차 작전] "가장 심각한 나라부터 도와주세요" → 성공 연출 → 지도 축소 → 연결 부활      (PHASE 4)
[S5 협력 작전] 협력 토큰 10pt를 지역 행동 + 공동 행동으로 지도에 배치                    (PHASE 5)
[S6 미래 시뮬] 1년→3년→5년 지도가 변한다. 남은 연결선 확인 → 1회 수정 기회              (PHASE 6)
[S7 세계 재연결] 나라들이 하나씩 빛나며 수집한 문화·악기 소리가 앙상블로 합쳐짐          (PHASE 7)
              → 3문장 메시지 → 세계 탐험 완성 지도 → 도장·인증서·엔딩 영상
```

## 2) 화면별 진행 순서 + 3) 학습 목표 + 4) 플레이어 행동 + 5) 상호작용

### 프롤로그 — 친구들의 긴급 통화 (40초)
- **목표**: Stage 1~5의 친구들이 "살아 있는 이웃"으로 재등장, 위기의 당사자화
- **행동**: 화면에 뜨는 친구 통화 카드 3~4장을 탭해 한 줄씩 듣는다 (기존 인사 친구 에셋 재사용)
- **상호작용**: 탭 → 짧은 대사 + 그 친구 대륙 위 신호 점등. 기존 1~3단계(인사·경청)는 이 프롤로그로 압축한다.

### S1 — 신호 지도 「뭔가 연결되어 있다」
- **목표**: 대륙별 환경 변화를 전/후 비교로 관찰. 문제는 각 스테이지에서 실제 다룬 것만 사용
  (아시아 물, 유럽 도시 폭염, 아프리카 물·숲, 아메리카 숲·물·생활 신호, 오세아니아 바다·해안)
- **행동**: 지도 팬/핀치 → 신호 터치 → 카드가 열리며 **과거↔현재 슬라이더**를 직접 끌어 장면 비교
  → "이곳 사람들의 하루가 어떻게 달라졌나" 한 줄 관찰 기록(선택지 3개 중 탭)
- **상호작용**: 팬/줌, 슬라이더(기존 environment.json의 before/afterAssetId 재사용), 관찰 선택
- **난타 검사**: 슬라이더를 끝까지 움직여야 관찰 선택지가 열린다. 신호 5개 중 4개 이상 관찰해야 다음.

### S2 — 나라 카드 연결 퍼즐
- **목표**: 원인→변화→생활→다른 지역 영향의 인과 구조를 학생이 직접 조립
- **행동**: 내 여행에서 모은 발견 카드(§8)가 보드에 흩어져 있다. 카드를 탭-탭으로 이어
  사슬 2개(예: 기후→강수→농업→식량→교류 / 플라스틱→강→바다→생물→여러 해안)를 완성
- **상호작용**: 카드 연결(선이 실시간으로 그어짐), 완성 순간 **세계지도 미니뷰에 같은 연결선이 켜진다**
- **피드백**: 잘못 이으면 X 대신 "이 다음에 무엇이 변했을까?" 질문 + 두 카드 확대. 화면 문구는
  "이 문제는 국경에서 멈추지 않았어요." 한 줄만.

### S3 — 입장을 바꿔보는 3개의 미니 시뮬 (각 20~30초)
- **목표**: 같은 문제라도 지역·조건에 따라 선택이 다를 수밖에 없음을 체감
- **행동/상호작용** (모두 드래그 배분, 정답 없음):
  1. **농촌**: 물 게이지 10칸을 생활·농사·가축 3통에 드래그 배분 → 어디를 줄여도 곤란한 결과가 짧게 보인다
  2. **해안**: 밀려온 쓰레기 앞에서 어업·관광·생태 중 먼저 지킬 것 배치 → 남은 두 곳의 여파 표시
  3. **도시**: 폭염 속 에너지 10칸을 냉방·교통·공공시설에 배분 → 취약한 사람 장면이 달라진다
- **피드백**: 정답/오답 없음. 배분 결과에 따라 장면이 달라지고, 마지막에 그 지역 친구의 한 줄
  "우리는 이래서 이렇게 선택할 수밖에 없었어." 학생 배분값은 저장해 S5 힌트로 재사용.

### S4 — 「한 나라만 해결해 보기」 (반전)
- **목표**: 단독 해결의 한계를 실패 경험으로
- **행동**: "가장 심각해 보이는 나라 하나를 먼저 도와주세요" → 학생이 나라 선택 → 지원 토큰 3개를 전부 그 나라에 배치 → 그 나라 신호가 꺼지는 성공 연출(색 회복, 주민 장면)
- **반전 연출**: 3초 후 지도가 자동으로 축소되며 바다·기후 연결선이 다시 그어지고 이웃 신호가 깜빡인다.
  중앙에 짧게: **"한 나라의 노력만으로는 부족합니다."**
- **난타 검사**: 이 실패는 회피 불가(어느 나라를 골라도 동일 구조) — 실패가 아니라 다음 화면의 동기.

### S5 — 세계 협력 작전 설계 (핵심 게임)
- **목표**: LOCAL+GLOBAL 조합의 필요성을 자원 제약 아래 전략으로 체험
- **행동**: **협력 포인트 10pt**. 행동 카드(비용 2~4)를 지도 위 대상 지역/연결선에 드래그 배치
  - 지역 행동(비용 낮음, 효과 좁음): 물 절약 캠페인, 숲 돌보기, 쓰레기 줄이기, 그늘 쉼터
  - 공동 행동(비용 높음, 연결선에 배치, 2개 대륙 이상 커버): 해양 쓰레기 공동 수거, 관측 데이터 공유, 환경 기술 교류, 환경 교육 교류
- **상호작용**: 카드 드래그 → 지역/연결선 슬롯, 포인트 게이지 실시간 감소, 카드 회수 가능
- **설계 규칙**: 공동 행동 없이는 연결선이 안 꺼지고, 지역 행동 없이는 마을 회복이 늦다 —
  좋은 결과는 반드시 혼합 조합에서 나온다(내부 판정: 연결선 커버리지 × 지역 커버리지).

### S6 — 미래 시뮬레이션 + 1회 수정
- **목표**: 결정→시간 경과→결과 관찰→수정의 문제 해결 루프
- **행동**: "작전 실행" → 지도 위 시간 배지가 1년→3년→5년으로 넘어가며 숲·물·바다·도시 장면이
  단계적으로 변한다(숫자 아님, 지도 색과 장면). 회복된 곳은 안정, 부족한 곳은 신호 잔존
- **수정 기회**: "아직 해결되지 않은 연결이 있어요." + 남은 연결선 하이라이트 → 토큰 재배치 1회
  → 재시뮬. 두 번째 결과는 어떤 조합이든 '세계가 함께 움직이기 시작한' 상태로 마무리(실패 화면 없음)
- **상호작용**: 시간 진행 관찰(탭으로 단계 넘김 가능), 재배치 드래그

### S7 — 세계가 다시 연결되는 순간 + 최종 보상
- **목표**: Stage 1~6 전체가 하나의 여행이었음을 감각으로 회수
- **연출**: 방문 순서대로 나라가 빛나고, 그 위에 내가 얻은 것들이 떠오른다 —
  배움 카드·문화 가방 선택(아메리카)·관심 나라 엽서(유럽)·내가 만든 8박 리듬(아프리카)·바다 제안(오세아니아)
- **음악 앙상블**: 나라가 켜질 때마다 그 지역 소리가 하나씩 겹친다(§15). 서로 다른 소리가
  각자의 특징을 유지한 채 하나의 곡으로 조화 — 섞어서 희석하지 않는다.
- **메시지**: 3문장을 순서대로 (장문 금지)
  "우리는 서로 다른 곳에서 살아갑니다." → "하지만 같은 지구에서 연결되어 있습니다." → "함께하면 더 멀리 바꿀 수 있습니다."
- **보상**: Stage 1~6 경로가 그려진 **세계 탐험 완성 지도**(문화 아이콘 표시) →
  "세계 연결 완료!" 배지 → 기존 도장 연출 → 완주 화면(#/completion)의 인증서·엔딩 영상(final.mp4)으로 연결

## 6) 성공/실패가 아닌 피드백 구조

| 상황 | 피드백 |
|---|---|
| 슬라이더 비교 | 정답 없음 — 관찰 선택 3개 모두 유효, 고른 것이 S2 카드 문구에 반영 |
| 연결 퍼즐 오연결 | X 금지 — "이 다음에 무엇이 변했을까?" 질문 + 카드 확대 재시도 |
| 입장 체험 | 어떤 배분도 완벽하지 않음 — 결과 차이만 보여주고 친구의 이유 한 줄 |
| 1차 작전 | 의도된 실패 — 비난 없이 연결선 부활을 보여주고 다음 화면의 동기로 |
| 협력 작전 1차 결과 | 남은 연결선 하이라이트 + 1회 수정 — 수정 과정 자체가 학습 |
| 최종 | 어떤 경로든 "함께 움직이기 시작한 세계"로 완결, 점수 숫자 강조 금지 |

## 9) 원인→영향→협력 해결 구조 (학습 뼈대)

```
관찰(S1 전/후)  →  연결(S2 인과 네트워크)  →  체감(S3 입장 배분)
→  판단의 한계(S4 단독 해결 실패)  →  협력 설계(S5 LOCAL+GLOBAL)
→  결과 확인·수정(S6 시간 시뮬)  →  종합(S7 재연결)
```
여섯 가지 도달점: ①나라별 상황이 다르다 ②같은 문제라도 영향이 다르다 ③다른 선택에는 이유가 있다
④문제는 국경을 넘는다 ⑤한 나라만으로 어렵다 ⑥지역 행동+국제 협력이 모두 필요하다.
각 항목이 특정 화면의 "행동"에 1:1로 대응한다(설명문 0줄).

## 10) 최종 보상 연출

나라 점등(순차) → 수집물 부상 → 앙상블 완성 → 3문장 → 완성 지도 줌아웃 →
"세계 연결 완료!" 배지 스탬프 → 기존 completeMissionFlow 도장 → 완주 화면에서 인증서·엔딩 영상(final.mp4).

## 11) 태블릿이어야 하는 이유 (§9 검사 — 8종)

핀치/팬 지도 · 전/후 슬라이더 · 카드 연결(선 그리기) · 게이지 드래그 배분 ·
토큰 지도 배치 · 시간 시뮬 실시간 변화 · 저장 데이터 재등장 · 소리 앙상블.
종이로는 "슬라이더로 5년을 되감기"와 "내가 만든 리듬이 엔딩에서 연주되는 것"이 불가능하다.

## 12) 화면별 UI 구성 (공통: 상단바 + 하단 행동바, 1화면 1행동)

- S1: 전체 지도 + 신호 핀 / 터치 시 우측 카드(장면+슬라이더+관찰 선택)
- S2: 상단 카드 트레이 + 중앙 연결 보드 + 우측 미니 지도(연결선 미러)
- S3: 좌측 장면 일러스트 + 우측 배분 게이지(칸 드래그) + 하단 결과 한 줄
- S4: 전체 지도 + 나라 선택 → 토큰 3개 슬롯 → 자동 줌아웃 반전
- S5: 전체 지도 + 하단 행동 카드 덱 + 좌상단 포인트 게이지(10칸)
- S6: 전체 지도 + 상단 연도 배지(1·3·5) + 남은 연결선 하이라이트 + 수정 버튼
- S7: 전체 지도 시네마틱(UI 최소화) + 3문장 오버레이 + 완성 지도 카드

## 13) 필요한 이미지 에셋 (신규 최소)

| 에셋 | 수량 | 비고 |
|---|---|---|
| 전/후 비교 장면 | 0~4 | 기존 environment.json before/after 재사용, 부족분만 신규 |
| 입장 체험 배경 3종(농촌·해안·도시) | 3 | 기존 대륙 장면 재활용 우선, 없으면 CSS 플레이스홀더 선반영 |
| 문화 아이콘 | 0 | 기존 수집물 에셋(학생 아바타·엽서·사진) 재사용 |
| 완성 지도 배경 | 0~1 | 기존 bg_map 위 CSS 경로선으로 시작 |
| 배지 "세계 연결 완료" | 0 | CSS+SVG 스탬프 |

## 14) CSS로 처리할 UI 요소

신호 핀 펄스, 전/후 슬라이더(클립 마스크), 연결선(SVG path + dash 애니), 배분 게이지(칸 드래그),
협력 포인트 게이지, 토큰 카드, 연도 배지, 나라 점등 글로우, 3문장 페이드, 배지 스탬프.
prefers-reduced-motion 전체 대응.

## 15) 애니메이션/사운드 연출

- 신호: 펄스 + 짧은 경고음(부드럽게, 공포 연출 금지)
- 연결선: dashoffset로 그어지는 애니 + '연결' 효과음
- 반전(S4): 줌아웃 + 연결선 재점화 — BGM이 반박자 가라앉았다가 S5에서 복귀
- 시뮬(S6): 연도 배지 넘어갈 때 지도 톤 변화(회색→초록 계열), 회복 지역에 반짝임
- **앙상블(S7)**: 실존 음원으로 구성 —
  ① 아프리카: `sound/instrument/*.mp3`(젬베·코라·칼림바) + **학생의 8박 리듬을 audio.playBeat 예약 재생**
  ② 각 대륙 BGM(stage1~5 mp3)의 첫 소절을 짧은 모티프로 순차 페이드-인 [가정: 추가 음원 없이 기존 5곡 활용]
  ③ 마지막에 메인 테마로 수렴. 각 소리는 자기 음색을 유지한 채 겹친다(볼륨 밸런스로 조화, 이펙트로 뭉개지 않음)
- 영상: 신규 컷신 없음 — 엔딩은 기존 final.mp4를 완주 화면에서 재생(이미 BGM 내장)

## 16) 최종 인증서·엔딩 영상 연결

S7 종료 → completeMissionFlow('dialogue') 도장 → 완주 화면(#/completion)이 열리며
세계 탐험 완성 지도가 회고·인증서 위에 함께 표시되고, "엔딩 보기" → final.mp4 → 엔딩 장면(기존 로직 유지).

## [가정] / [검증 필요]

- [가정] 플레이 시간 14~18분(현행 14분에서 소폭 증가). 프롤로그 압축으로 상쇄

- [가정] 미완료 스테이지 대륙은 "친구의 소식"으로 대체해 진행 차단 없음 (교사용 해금과 동일 원칙)
- [검증 필요] 환경 사례 문구 전체(needsReview 유지, 출처 확정 전 단정 금지) · 지역 시뮬 3종의 수치 설정이 특정 국가 비하로 읽히지 않는지 learning-check 검수

## 자기비평 (RED FLAG 검사)

- **강점**: 실패(S4)를 게임 장치로 쓰는 서사 / 수집물 재사용으로 6이 1~5의 결론이 됨 / 상호작용 8종 전부 학습 행동과 1:1
- **약점**: ① S5 판정(커버리지 조합)이 단순하면 아무 혼합이나 통과 — 연결선별 요구 조건을 콘텐츠에 명시할 것 ② S6 시간 시뮬이 연출만 있고 관찰할 게 없으면 영상 시청이 됨 — 연도마다 "달라진 곳 1곳 탭해 확인"을 넣어 관찰을 행동화 ③ 화면 7개는 분량 상한 — 프롤로그·S4는 각 1분 이내로 엄수
- **반드시 개선**: S2 카드 풀이 세이브 상태에 따라 달라지므로, 어떤 조합에서도 사슬 2개가 성립하도록 콘텐츠 폴백 카드를 정의할 것

> **이 기획의 진짜 게임 행동 한 문장**: "내가 모은 발견으로 문제의 연결을 직접 잇고, 한 나라 구하기의 실패를 겪은 뒤, 제한된 토큰으로 지역+세계 조합 작전을 설계해 5년 뒤 지도가 회복되는 것을 지켜본다."
