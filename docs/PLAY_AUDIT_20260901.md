## 1. 직접 플레이에서 확인한 흐름 (요약)

전체 서사 흐름 자체는 **잘 이어져 있다**. 인트로 영상(약 16초, 건너뛰기 가능) → 여권 3단계 → 지도 → 대륙마다 "탐험 → 친구 만남 → 이야기 수집 → 환경 신호로 변환 → 도장" → 지구회의 가방에 14개 신호가 실제로 쌓이고, 스테이지 6에서 그 목록이 다시 열리며 회수된다. 다문화(친구들의 서로 다른 하루) → 세계지리(대륙·지형 탐험) → 공통 환경 문제(신호→렌즈 연결→공동 약속)로 이어지는 교육 설계는 명확하고, 흐름에서 벗어나거나 방해되는 페이지는 **없었다**.

문제는 흐름이 아니라 **밀도와 리듬**: 판단이 필요한 조작보다 "읽고 탭"이 압도적으로 많고, 같은 템플릿이 대륙 안에서 4~6회, 대륙 간에도 반복된다.

## 3. "교과서 느낌"의 원인 (실측 기반)

1. **대화 = 전부 일방향.** 노아·카밀라·루카·조피아·스테이지6 친구 6명… 모든 대화가 "다음" 6연타. 학생이 고르는 문장이 하나도 없다. 내 캐릭터(바다)의 대사도 자동 재생.
2. **'꼭 알아둘 것' 카드 동일 포맷 반복.** 매 스테이지 시작·중간에 같은 노란 카드 2문장 → 탭. 5번째부터는 안 읽게 됨.
3. **관문 대부분이 난타 통과 가능.** 정오답이 있는 건 아메리카 하루-매칭(4), 스티커 분류, 아프리카 리듬 규칙 3종, 지구회의 렌즈 3지선다, O/X 1개 정도. 나머지는 "다 누르면 통과".
4. **아시아·오세아니아 완전 동일 템플릿.** 권역 4 → 나라 6 → 장면 4(핫스팟 2탭) → 신호 3 → 목소리 2 → 행동 3. 연속으로 하면 두 번째는 작업처럼 느껴짐.
5. **페이스 변화 없음.** 아프리카 리듬(최고 재미) 이후로 다시 읽기-탭 위주로 복귀. 긴장(제한·실패·서프라이즈)이 주는 각성 구간이 게임 전체에 1곳뿐.
