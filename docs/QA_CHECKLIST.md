# QA_CHECKLIST — 세계를 잇는 여행

결과 표기: ✅ 통과 / ⚠ 부분 / ❌ 실패 / ⬜ 미실시. 실측 후 갱신한다.

## 1. 기능

- ⬜ 1~10페이지가 정상 경로로 모두 열린다
- ⬜ 타이틀→수료증 전체 플레이 1회 성공
- ⬜ 이어하기: 저장 있을 때만 활성화, lastRoute로 복귀
- ⬜ 새로고침 후 미션 체크포인트에서 이어짐
- ⬜ 5개 대륙 미션이 서로 다른 핵심 조작 사용
- ⬜ 대화 미션은 5대륙 완료 전 잠김 (지도에서 시각·의미 구분)
- ⬜ `#/completion` 직접 접근 시 지도로 리다이렉트 (해금 전)
- ⬜ 새 게임 시 확인 모달, 취소하면 데이터 유지

## 2. 저장·복구

- ⬜ 손상된 localStorage(JSON 깨짐)에서도 크래시 없이 기본값 시작 (vitest 통과 + 수동 1회)
- ⬜ 보상·스탬프 중복 지급 없음 (vitest 통과)
- ⬜ 저장 조작(unlocked:true 주입)해도 완료 페이지 안 열림 (vitest 통과)

## 3. 입력·안정성

- ⬜ 빠른 연속 클릭: 장면 전환·모달·완료 처리 중복 없음
- ⬜ 드래그 도중 화면 밖으로 나가도 상태 안 깨짐
- ⬜ 키보드만으로 미션 진행 가능 (Tab + Enter/Space)
- ⬜ 탭-선택 → 탭-배치 대체 조작 동작 (터치)

## 4. 오디오

- ⬜ 첫 사용자 입력 전 자동재생 없음 (콘솔 경고 없음)
- ⬜ BGM 페이지 전환 crossfade, 중첩 재생 없음
- ⬜ 음소거 상태 저장·복원
- ⬜ 소리 끈 상태로 아프리카 미션 포함 전체 완주 가능 (시각 박자)
- ⬜ SFX 파일 삭제 상태에서도 게임 진행 (무음 폴백)

## 5. 반응형·태블릿

- ⬜ 1920×1080 / 1366×768 / 1024×576 잘림 없음
- ⬜ 태블릿 가로 16:9 터치 동작, 최소 터치 44px(지도 56px)
- ⬜ 브라우저 확대 200%에서 핵심 진행 가능
- ⬜ 한글 어절 단위 줄바꿈, 버튼 밖 글자 넘침 없음

## 6. 학습·문화 안전성

- ⬜ 오답 시 "틀렸어요" 단독 표시 없음 — 이유+단서+재도전 제공
- ⬜ 부분 점수·복수 해 동작 (5·7·8p)
- ⬜ 인사 사례에 caution 문구 표시 (vitest + 화면 확인)
- ⬜ 단일 문화 단정 문항 없음 (콘텐츠 검수 — 교사 최종 검수 필요 표시)

## 7. 성능·정리

- ⬜ production 빌드 성공, 초기 다운로드 5~8MB 이내
- ⬜ 장면 이탈 시 Phaser 인스턴스·타이머·리스너 정리 (아프리카 시퀀서 재생 중 이탈 포함)
- ⬜ 콘솔에 처리되지 않은 오류 없음 (전체 플레이 기준)

## 8. 배포 (배포 시)

- ⬜ 정적 호스팅에서 해시 라우트 직접 접근 정상
- ⬜ 대소문자 경로 문제 없음 (Linux 서버)
- ⬜ og.webp·favicon 표시

## 브라우저

- ⬜ Chrome (기준) / ⬜ Edge / ⬜ 태블릿 Chrome 또는 Safari
