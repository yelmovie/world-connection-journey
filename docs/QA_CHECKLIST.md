## 핵심 기능 실측

- 전체 플레이: 아시아 100, 유럽 100(목적이 다른 두 경로), 아프리카 100, 아메리카 100(두 일정 비교), 오세아니아 96(3턴 결과 비교), 대화 100 후 완료 페이지 진입.
- 저장: 아시아 관찰 1/6 상태를 새로고침 뒤 복원했고 이어하기가 같은 지점으로 돌아왔다. 퍼즐 조각·회고 초안·실천 약속도 즉시 저장하도록 구현·테스트했다.
- 접근 가드: 5대륙 완료 전 대화, 모든 미션 완료 전 인증 직접 접근이 지도로 리다이렉트됨을 확인했다.
- 반응형: 512×288은 compact/no canvas, 915×412·1024×576·1024×768·1280×800·1366×768·1920×1080은 지도 canvas 1개와 핵심 컨트롤 접근을 확인했다.
- 모달: 포커스 트랩, Escape 닫기, 원래 포커스 복원, 라우트 전환 시 정리를 확인했다.
- 콘솔: 최종 미리보기 기준 warn/error 0.
