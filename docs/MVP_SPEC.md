# MVP_SPEC — 세계를 잇는 여행

## 대상·목표

- 대상: 초등학교 6학년 (사회 6-2 '지구촌 사람들'), 초등 고학년 수준
- 세션: 35~60분, 개별 플레이 중심 (짝 토론 병행 가능)
- 핵심 학습 순환: 관찰 → 증거 찾기 → 가설 세우기 → 질문하기 → 경청하기 → 판단 수정하기
- 성취기준: [6사09-01] [6사09-02] [6사10-01] [6사10-02] [6사12-02] (README 표 참조)

## 디지털 게임이어야 하는 이유

정적 학습지로 불가능한 조작을 각 페이지가 하나 이상 가진다:
드래그 배치·분류(4·7p), 지도 경로 설계와 실시간 지표(5p), 소리·시각 동기화 리듬 시퀀서(6p),
조건에 따라 결과가 달라지는 결정론 3턴 시뮬레이션(8p), 제약 일정의 대안 비교(7p), 분기형 대화(9p), 저장·이어하기(전체),
부분 점수와 재도전(전체), 복수 해 허용(5·7·8p).

## 포함 범위 (MVP)

- 10페이지 전체 흐름, 5대륙 미션 + 대화 미션 실제 플레이
- 저장·이어하기·체크포인트, 손상 복구, 해금 재계산(완료 페이지 직접 접근 차단)
- BGM 6곡 + SFX 10종 + 시각 피드백, 설정(BGM/SFX/모션 감소)
- 반응형(1920/1366/1024, 태블릿 16:9), 터치·마우스·키보드, 탭-선택 대체 조작
- 인쇄용 수료증, Vitest 7파일·32테스트, production 빌드

## 제외 범위 (MVP 이후)

- Three.js 3D (의존성·GLB 없음). 현재는 `passport-stamp`→`prop.stamp`, `completion-globe`→`reward.globe_puzzle` 이미지 폴백 위치만 예약
- 교사 대시보드·학급 코드·서버 저장, 다국어(영어) 콘텐츠
- 문항은행 확장(현재 미션당 1세트), 성취도 리포트 내보내기
- PWA 오프라인 캐시 (배포 후 classroom-ready 점검 시 추가 검토)

## 완료 조건 (Definition of Done)

1. `npm run verify` (typecheck+test+build) 통과 — **완료**
2. 타이틀→수료증 전체 플레이 1회 실측 성공 — **완료**
3. 새로고침 후 최신 체크포인트에서 이어하기 — **완료**
4. 5개 미션이 서로 다른 핵심 조작 사용 — **완료**
5. 모든 오디오 활동에 시각 단서와 키보드·탭 대체 조작 제공 — **구현 확인**, 무음·키보드만의 전체 종단 플레이는 별도 실기기 재확인 필요
6. 대표 데스크톱·태블릿·작은 가로 화면에서 핵심 진행과 스크롤 접근 — **브라우저 확인**, 실제 회전·200% 전체 종단·실기기 검증은 남음
7. 문서(README/TRD/ASSET_AUDIT/QA_CHECKLIST)가 코드와 일치 — **이번 점검에서 갱신**

## 출시 조건

로컬 MVP 기능은 완료됐다. 다만 콘텐츠 7종은 모두 `needsReview: true`이고 교육 내용 출처·검토자·라이선스 메타데이터가 미완성이다. Git 원격·호스팅도 아직 없으므로 공식 수업이나 공개 배포 전에는 교사 검토·출처 보강, 학교망/실기기 확인, 실제 배포 URL의 딥링크·저장 smoke test가 필요하다. 최종 판정은 **조건부 배포 가능**이다.
