## 개선 내용

### 1. 로딩 진행률 표시

- **무엇을**: 화면 전환·초기 로딩 시 스피너만 돌던 로딩 화면에 진행률 표시를 추가.
- **왜**: QA 17번 — 라우트 분할과 로딩 화면은 확인됐지만, Phaser lazy 청크(gzip 332.40kB)를 받는 동안 학생이 멈춘 것인지 로딩 중인지 구분할 수 없었습니다. 학교망처럼 느린 회선에서 특히 문제가 됩니다.
- **어떻게**: 기존 라우터의 로딩 화면(`src/router.ts`)을 유지한 채 진행 상태를 표시하도록 확장.

### 2. 오프라인 캐시 (PWA)

- **왜**: QA 19번 — 런타임 외부 요청은 0이지만 서비스워커가 없어, 수업 중 Wi-Fi가 끊기면 새로고침 시 게임이 열리지 않았습니다. "PWA 캐시 없음"이 감점 사유로 명시돼 있었습니다.
- **무엇을·어떻게**: 서비스워커 기반 오프라인 캐시를 도입해 첫 방문 이후에는 네트워크 없이도 재방문·새로고침이 가능하게 함. 저장 데이터는 원래 `localStorage`뿐이라 오프라인과 무관하게 유지됩니다.

### 3. 볼륨 조절

- **왜**: QA 15번 — 전역 AudioManager와 BGM/SFX 켜기·끄기는 있었지만 크기 조절이 없어, 교실에서 "소리를 줄여서" 쓰는 중간 단계가 불가능했습니다.
- **무엇을·어떻게**: 설정에 BGM·SFX 볼륨 조절을 추가하고 저장값에 보존. 기존 토글(끄기)과 시각 박자점(리듬 미션의 무음 대체 수단)은 그대로 유지합니다.

### 4. 본문 폰트 상향

- **왜**: QA 12번 — 16px 절대 하한과 `word-break: keep-all`은 지켰지만, 전자칠판 뒷자리 기준 본문 권장 20px를 전부 충족하지 못한다는 감점이 있었습니다.
- **무엇을·어떻게**: 디자인 토큰(`src/styles/tokens.css`)의 본문 글자 크기 단계를 상향해, 개별 화면 수정 없이 전 화면에 일괄 반영.

### 5. 세로 모드 안내

- **왜**: QA 13번 — 이 게임은 태블릿 가로(16:9) 기준으로 설계했는데, 실제 기기에서 세로로 들었을 때의 동작이 미실측 위험으로 남아 있었습니다.
- **무엇을·어떻게**: 세로 방향 감지 시 가로로 돌려서 사용하도록 안내를 표시. 강제 차단이 아니라 안내이므로 진행 데이터에는 영향이 없습니다.

### 6. 문서 보강

- **왜**: QA 21번 — README·TRD·MVP·에셋·QA 문서는 있었지만 제작기·기능향상기가 없고, 다른 교사·개발자가 새 미션을 추가하는 절차 문서가 없다는 감점이 있었습니다.
- **무엇을·어떻게**:
  - README에 **"새 스테이지(미션) 추가 방법"** 섹션 추가 — 콘텐츠 JSON → 페이지 모듈 → 라우트·타입 등록 → 테스트의 4단계를 실존 파일 경로로 안내.
  - [docs/제작기.md](제작기.md) 신규 작성 — 기획 의도, 상호작용 설계, 기술 구조, 에셋 파이프라인, 문화적 안전장치.
  - 본 문서(기능향상기) 신규 작성.
  - [docs/icon-prompts.md](icon-prompts.md) 신규 작성 — UI 이모지 사용 현황(0건)과 향후 아이콘 추가 규격.

### 7. 에셋 정리

- **왜**: QA 18번 — 코드에서 참조하지 않는 semantic ID 11개가 빌드에 남아 있고, 미배정 원본 93장은 목록만 있고 처리 방침이 없었습니다.
- **무엇을·어떻게**:
  - `src/content/asset-manifest.json`의 미참조 11개 항목(`bg.spare`, `prop.globe`, `prop.suitcase`, `asia.child1~3`, `europe.guide`, `europe.heritage`, `africa.instrument2~3`, `oceania.island`)을 삭제하지 않고 `pages: []`와 "미사용 — 향후 확장용" note로 표시 — 향후 확장 시 바로 재사용할 수 있게 보존.
  - [_unused/DELETE-CANDIDATES.md](../_unused/DELETE-CANDIDATES.md) 신규 작성 — 중복 23장, 미배정 원본 93장(144.6MiB), 미참조 WebP 목록을 근거와 함께 기록. 실제 삭제는 하지 않고 후보만 정리.
  - [docs/ASSET_AUDIT.md](ASSET_AUDIT.md)에 이번 정리 결과 반영.
