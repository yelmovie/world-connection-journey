# 최종 단계 "하나의 지구, 여섯 개의 신호" — 환경 시각 자료 목록과 프롬프트

> 작성일: 2026-08-30. 화면 코드는 `src/pages/earthCouncilScenes.ts`, 콘텐츠는 `public/content/v1/ko/environment.json`.
> 생성 이미지는 모두 **개념 일러스트**다. 특정 지역의 현재 상태를 기록한 사진이 아니며, 화면에는 항상
> "이 장면은 이 친구가 사는 지역에서 관찰한 여러 모습 중 하나예요" 범위 안내와 함께 표시한다.

## 공통 규칙

- 1이미지 = 1장, 콜라주 금지, 이미지 안 글자 금지(자막·버튼은 HTML/CSS/SVG).
- 16:9, 권장 1600×900 이상 → `public/assets/*.webp` 로 변환(품질 82, 폭 1600).
- 초등 고학년용 프리미엄 교육게임 일러스트. 충격적·공포스러운 표현 금지.
- 특정 국가를 더럽거나 낙후된 곳으로 그리지 않는다. 특정 민족·외모·의상을 환경문제와 연결하지 않는다(사람은 넣지 않거나 배경 실루엣만).
- 원본은 `assets/environment/`, 매핑은 `src/content/asset-manifest.json` + `scripts/asset-map.json`, 출처 표기는 `assets/CREDITS.md`.
