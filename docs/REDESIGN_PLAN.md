### 화면 텍스트 예산

- 상단: 제목 1개. 부제는 원칙적으로 제거한다.
- 캐릭터 말풍선: 한 번에 32~40자, 한 문장. 탭하면 즉시 전체 표시한다.
- 본문: 현재 행동을 설명하는 고정 문장은 두지 않고 그림·한 줄 라벨로 구성한다.

- 선택지: 한 번에 4개 이하. 더 많으면 단계·그룹·가로 선반으로 나눈다.
- 하단: Primary CTA 1개. 보조 행동은 상세 보기 또는 이전 단계 안에 둔다.

## 2. 재설계 원칙

1. **한 화면, 한 행동**: 학생은 5초 안에 지금 할 일을 알아야 한다.
2. **배경이 아니라 장면**: 인물·소품·랜드마크는 가장자리 장식이 아니라 선택·비교·배치의 학습 단서가 된다.
3. **샘플 구도 준수**: 좌측 단서/진행, 중앙 핵심 게임판, 우측 분석/결과, 하단 단일 주 행동을 기본으로 한다.
4. **미션마다 다른 실루엣**: 같은 흰 카드 그리드를 반복하지 않는다.
5. **보상은 다음 행동을 만든다**: 스티커·여권 도장·항로가 지도와 여권에 누적된다.
6. **짧고 강한 피드백**: 정답/배치 시 300ms 안의 바운스·파티클·SFX를 동기화하고 설명은 계속 읽을 수 있게 둔다.
7. **접근성은 게임성의 일부**: 48px 터치, 핵심 안내 18px+, 키보드·탭 대체, 무음 시각 단서, 모션 감소를 유지한다.
8. **기반 로직 보존**: 저장 키, 판정 함수, 체크포인트, 콘텐츠 JSON, EventBus 이름은 유지한다.

## 3. 공통 화면 언어

- **탐험 티켓 HUD**: 현재 대륙, 미션 목표 한 문장, 3단계 진행 점을 상단에 고정한다.
- **리본 제목**: 각 장면의 학습 목표를 배경 위 독립 리본으로 표시한다.
- **장면형 게임판**: 불투명한 전체 흰 패널 대신 중앙 2.5D 배경과 반투명 작업판을 사용한다.
- **가이드 말풍선**: 마스코트는 현재 행동을 한 문장으로만 안내하고 학습 내용을 반복하지 않는다.
- **하단 행동 도크**: 주 행동 버튼은 오른쪽, 단계·수집 상태는 왼쪽에 고정한다.
- **수집 선반**: 지역 스티커와 도장 6개를 지도·여권·완료 화면에서 같은 모양으로 보여 준다.
- **상태 표현**: 색 + 아이콘 + 테두리 + 문구 중 최소 3개로 정답·부분정답·재도전을 구분한다.

## 4. 전체 흐름

1. **타이틀** — 샘플 1 구도, 하나의 강한 `새 여행 시작` 행동
2. **3컷 프롤로그** — 마스코트가 `관찰 → 물어보기 → 생각 바꾸기`를 20초 안에 안내
3. **여권** — 별명·탐험가·비행기를 고르고 즉시 지도 입장
4. **세계지도** — 좌측 진행 티켓, 중앙 원형 랜드마크 노드와 항로, 우측 선택 미션 미리보기
5. **비행 전환** — 선택한 대륙의 색·배경·목표를 400ms 이하로 예고
6. **미션 플레이** — 장면마다 한 행동, 3~4단계, 즉시 시각·음향 피드백
7. **미션 결과** — 배움 한 줄·스티커·도장 쾅, `지도에서 다음 지역 고르기`
8. **지도 복귀** — 새 도장 위치가 채워지고 다음 추천 노드가 한 번만 강조됨
9. **대화 미션** — 5대륙의 단서를 모아 공감 나침반 완성
10. **완료** — 퍼즐 지구본, 보상 바, 회고, 수료증 보드를 한 성취 장면으로 통합

| 아메리카 | 국제 교실 + 네 학생 토큰 + 일정 보드 | 인물 필요 확인 → 일정에 토큰 배치 → 충돌 해결 → 대안 A/B 비교 |
| 오세아니아 | 섬 지도 + 네 관점 인물 + 영향 계기판 | 지점 조사 → 관점 초대 → 계획 조정 → 단기/장기 숫자 변화 → 수정 |
| 대화 | 반원형 국제 라운지 + 공감 나침반 + 말풍선 | 상황 보기 → 추측과 사실 분리 → 질문/경청 선택 → 판단 수정 |

## 6. 에셋 목표

- manifest 110개 중 **88개 이상을 실제 화면에 렌더**한다.
- 페이지당 독립 래스터는 최대 10개, 동시 강조는 최대 3개로 제한한다.
- 배경·캐릭터·학습 단서·보상·전환의 역할을 구분하고 단순 장식만을 위해 억지로 배치하지 않는다.
- 전통의상·음식·랜드마크는 대륙 전체의 대표가 아니라 **특정 자료의 한 사례**로 문맥과 함께 쓴다.
- 에셋 파일명은 변경하지 않고 semantic ID와 기존 manifest를 사용한다.

## 7. 구현 트랙

### 트랙 A — 공통 흐름과 보상

`tokens.css`, `base.css`, `components.css`, 공통 FX/피드백, 타이틀·프롤로그·여권·지도·완료 화면을 담당한다.

### 트랙 B — 아시아·유럽·아프리카

세 미션을 각각 기록 퍼즐, 경로 전략게임, 리듬 협력게임으로 재구성한다. 기존 판정·체크포인트는 보존한다.

### 트랙 C — 아메리카·오세아니아·대화

세 미션을 국제 교실 계획, 섬 공동체 시뮬레이션, 공감 라운지로 재구성한다. 현재 `NPC_IMG` 누락 타입 오류도 이 트랙에서 복구한다.

## 8. 완료 조건

- 타이틀부터 완료까지 화면 흐름을 설명 없이 이해할 수 있다.
- 6개 미션의 첫 화면 실루엣과 핵심 조작이 서로 다르다.
- 에셋 실사용률 80% 이상을 정적 목록과 실제 화면으로 확인한다.
- 모든 성공·부분정답·재도전에 시각·문구·소리 피드백이 연결된다.
- 1024×576과 1280×800에서 스크롤 없이 현재 행동과 주 버튼이 보인다.
- 키보드·무음·모션 감소로도 완주할 수 있다.
- `npm run verify`가 통과하고 브라우저 콘솔 오류가 없다.
- 같은 21항목으로 다시 채점하며 확인하지 않은 항목을 고득점 처리하지 않는다.
